Aim77 privacy policy

Last updated November 12, 2026

Aim77 is a personal, single-user app that runs on its developer's own computer. This policy explains what it does with Google user data.

What Aim77 accesses

  • Google Calendar (calendar.events): reads the user's events to show them in the app, and creates or updates events for tasks the user chooses to schedule.
  • Gmail (gmail.modify): reads messages in the user's own inbox to show them in the app, moves a message to the Trash when the user presses Delete, and sends or drafts a reply when the user writes one and presses Send or Save as draft.

How the data is used, stored and shared

Google data is used only to provide these features to the user. It is stored only on the user's own computer. Aim77 has no server of its own, no cloud database, no advertising and no analytics, and it never sells Google data or uses it for advertising.

The only transfer is this: to write short summaries of new email and list to-dos, the text of a new message is sent to Anthropic's Claude through the user's own Claude account, used only to produce that summary for the user. No humans read the data except the user.

Aim77's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Retention and removal

Access can be removed at any time from Aim77's Settings (Remove / Disconnect) or at myaccount.google.com/permissions. Removing it deletes the stored sign-in from the user's computer, and the user can delete any stored messages by deleting the app's files.
